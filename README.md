# Network-Intrusion-Detection-with-Security-Onion-and-Snort
Network security monitoring project: I deployed a Snort IDS sensor on Security Onion, fed it traffic via Hyper-V port mirroring, and attacked the network from Kali Linux to see what it caught. I triaged alerts in Sguil, tuned out a noisy rule, and analyzed signatures fired by recon scans and a SYN flood.
